# AI Image Enhancer

A Python tool that upscales and enhances image resolution using an AI image-processing API.

## 🚀 Features
- Upscales low-resolution images to higher resolution
- Enhances overall image quality
- Simple, lightweight Python implementation

## 🛠️ Tech Stack
- **Language:** Python
- **Integration:** Third-party AI image-processing API

## ⚙️ Setup

1. Clone the repository
   ```bash
   git clone https://github.com/shubhamsunita7-ui/ai-image-enhancer.git
   cd ai-image-enhancer
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Add your API key
   - Create a `.env` file in the project root
   - Add your API key like this:
     ```
     API_KEY=your_api_key_here
     ```

4. Run the script
   ```bash
   python main.py
   ```

## 📸 How It Works
The script takes an input image, sends it to the AI image-processing API, and returns an enhanced, higher-resolution version of the image.
